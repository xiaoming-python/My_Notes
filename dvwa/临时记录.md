## 命令行注入
- 利用网站上的特定功能模块，可能是利用服务器的命令行实现的（例如：`ping ip`地址），可以尝试在正常命令后加入其他命令执行
### 一、 命令连接符（Command Separators）

这些符号的作用是把多条命令拼接在一起执行。

#### 1. 通用（Windows & Linux 都支持）

|符号|名称|行为说明|示例|
|---|---|---|---|
|`&&`|逻辑与|**前一条命令成功**执行后，才执行后一条命令。|`ping 127.0.0.1 && whoami`|
|`\|`|逻辑或|**前一条命令失败**后，才执行后一条命令。|`ping 不存在的IP \| whoami`|
|`\|`|管道符|把前一条命令的**输出结果**，作为后一条命令的**输入**。|`ping 127.0.0.1 \| whoami`|
|`%0a` / `%0d`|换行符|URL 编码的换行符，经常被解析为命令分隔符。|`ping 127.0.0.1%0awhoami`|

#### 2. Windows 专属

|符号|名称|行为说明|示例|
|---|---|---|---|
|`&`|顺序执行|**无论前一条是否成功**，都执行后一条。|`ping 127.0.0.1 & whoami`|
|`,`|逗号|有时被当作参数分隔符，在某些上下文中可代替空格。|`ping,127.0.0.1`|

#### 3. Linux 专属

|符号|名称|行为说明|示例|
|---|---|---|---|
|`;`|分号|**无论前一条是否成功**，都执行后一条。|`ping -c 1 127.0.0.1; whoami`|
|`` ` `` \| 反引号 \| 命令替换，先执行反引号内的命令，将结果返回。 \| `` ping `whoami` `` \|||||
|`$()`|美元括号|同上，命令替换（比反引号更现代）。|`ping $(whoami)`|

### 二、 代替空格的方法（Space Bypass）

在注入时，如果 Web 应用的 WAF（防火墙）或代码把**空格**给过滤了，你可以使用以下方法绕过：

#### 1. Linux 环境

Linux 的 Shell 极其灵活，有很多奇技淫巧：

- **`$IFS` 系列（最常用）**：  
    `IFS` 是 Linux 的内部字段分隔符，默认包含空格、Tab 等。
    
    - 使用：`cat$IFS/etc/passwd` （替换了 `cat /etc/passwd` 中的空格）
        
    - 进阶：有时候 `$IFS` 会被过滤，可以用 `$IFS$9`（9代表当前脚本的第9个参数，通常为空，能截断IFS）。例：‘cat9代表当前脚本的第9个参数，通常为空，能截断IFS）。例：‘catIFS$9/etc/passwd`
        
    - 再进阶：`${IFS}`
        
- **`<` 或 `>` 重定向符**：
    
    - 使用：`cat</etc/passwd`（把文件内容重定向输入给 cat）
        
- **`%09` (Tab 键)**：
    
    - 在 URL 中传递 `%09`，很多程序会将其解析为 Tab 空白符，从而绕过只有空格的过滤。
        
- **`{...}` 大括号扩展**：
    
    - 使用：`{cat,/etc/passwd}`，Linux 会自动将其扩展为 `cat /etc/passwd`。
        

#### 2. Windows 环境

Windows 的 CMD 比较死板，可代替空格的符号较少：

- **`%09` (Tab 键)**：
    
    - 和 Linux 一样，在 URL 里输入 `%09`，如 `ping%09127.0.0.1`。
        
- **`%20` (URL 编码的空格)**：
    
    - 如果后端没做解码，直接输入 `%20` 有时能骗过后端的过滤，到达系统层时解析为空格。
        
- **逗号 `,` 或 分号 `;`**：
    
    - 在 Windows CMD 中，某些命令（如 `type`、`dir`）可以接受逗号或分号作为参数分隔。例如：`dir,C:\`。
        
- **双引号 `""`**：
    
    - 有时在参数中间插入 `""` 可以绕过。比如 `ping "127.0.0.1"`。
        
- **环境变量截取（高级）**：
    
    - Windows 可以在命令里直接读取环境变量来拼凑空格，但极其复杂。
