# `php`简介
- `php`是老牌的web后端语言
- `php`文件后缀名是`.php`,在`.php`中可以运行`php`代码,也可以运行`html`代码
# 基础语法
- `php`必须被包围于`<?php ?>`之中
- 输出：`echo` `print`
```php
<?php
echo ""hello\n";//无返回值
print("php\n");//有返回值，返回1
?>
```
在`<?php ?>`标签外的语句都被自动输出到标准输出
## 变量
- `php` 普通变量以`$`开头
```php
<?php 
$name="xiaoming";
?>
```
数组变量
```php
<?php
$list=[
"num"=>1,
"sub"=>2
]
?>
```
- `"num"`：**键**（索引、名字，用来找数据）
- `=>`：**映射**，代表左边这个键 对应 右边这个值
- `"1"`：**值**（真正存的数据）
