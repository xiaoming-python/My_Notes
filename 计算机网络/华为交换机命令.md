## 一，系统基础命令
- `<SW1>system-view` (用户视图)进入系统视图
- `[SW1]sysname new` 改变设备名称(改为new)
- `[SW1]interface GigabitEthernet 0/0/1` 进入`0/0/1`接口视图
- `[SW1-GE...]ip address 192.168.1.1 24` （接口视图）设置ip地址
- `[SW1]quit` 退出,返回上一次视图
- `<SW1>save` 保存
- `[SW1]return` 返回用户视图
- `[SW1]user-interface vty 0 4` 进入`vty`虚拟终端路线视图
- `[SW1-ui-vty0-4]authentication-mode password` 设置密码
- `[SW1-ui-vty0-4]user privilege level 1` 设置远程登录上来的用户权限等价=1级
- `[SW1]?` 帮助
- `<SW1>reboot` 重启
- `[SW1]undo` 撤销
- `[SW1]undo info-center enable` 关闭设备全局日志
- `[SW1]un in en`关闭日志

## 二，虚拟局域网技术
-  `[SW1]vlan batch 10 20` 创建两个`VLAN ID` 号10和20
- `[SW1-GE...]port link-type access` 将接口类型设为access(接入)
- `[SW1-GE...]port default vlan 10` 把当前接口划入 `VLAN 10`，并且把这个接口的默认 `VLAN`设置为 10

## 三，`STP`配置
- `[SW1]stp mode stp` 将交换机的生成树协议模式切换为标准 `STP`
- `[SW1]stp enable`  开启生成树协议
- `[SW1]stp root primary` 设为根桥
- `[SW1]stp root secondary`设为次根桥
- `[SW1]dis stp brief` 查看`STP`配置
- `[SW1]display stp interface GE...`查看端口开销
## 四，`MSTP`的配置
- `[SW1]vlan batch 10 20` 创建两个`VLAN ID` 号10和20
- `[SW1-GE...]port link-type trunk` 将端口类型设为`trunk`(中转)
- `[SW1-GE...]port trunk allow-pass vlan all` 允许所以`vlan`通过`trunk`端口
- `[SW1]stp mode mstp`将交换机的生成树协议模式切换为 `MSTP`
- `[SW1]stp region-configuration` 进入`mstp`配置视图
- `[SW1-mst-r...]region-name huanwei` 设置别名为`huanwei`
- `[SW1-mst-r...]instance 1 vlan 10` 把`vlan10`映射到实例1中
- `[SW1-mst-r...]active region-configuration`激活使配置生效
- `[SW1]stp instance 1 priority 0`将`sw1`配置为实例1的主根
 -- **注意**：0最小为根，优先值的范围限制：0 ~ 61440，优先级不能是任意数字，它必须是 4096 的整数倍，**合法的优先级数值只有这 16 个**：  
`0`、`4096`、`8192`、`12288`、`16384`、`20480`、`24576`、`28672`、  
`32768`（华为默认值）、`36864`、`40960`、`45056`、`49152`、`53248`、`57344`、`61440`。
- `[SW1]stp enable` 激活`STP`
