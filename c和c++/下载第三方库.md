# 方法一，使用vcpkg
C/C++ 包管理器，类比 Python 的 pip
## 步骤 1：安装 vcpkg

打开 PowerShell

powershell

```powershell
git clone https://github.com/microsoft/vcpkg.git
cd vcpkg
.\bootstrap-vcpkg.bat
```

## 步骤 2：安装 libuv 套接字库

powershell

```powershell
# x64动态库（常用）
.\vcpkg install libuv:x64-windows

# 如果你想要静态库（打包exe不用带dll）
# .\vcpkg install libuv:x64-windows-static
```

## 3. 创建构建目录，执行 CMake 生成 MinGW Makefile

```powershell
cd E:\c++\install\libuv-1.52.1
rmdir /s /q build
mkdir build
cd build
cmake -G "MinGW Makefiles" -DCMAKE_INSTALL_PREFIX=E:\C++\libuv_install ..
```
-DCMAKE_INSTALL_PREFI=安装文件目录
## 4. 编译 && 安装


```powershell
mingw32-make
mingw32-make install
```

## 5. 编译后产物目录 `E:\C++\libuv_install`


```plaintext
libuv_install
├─ include/         # uv.h头文件，代码 #include <uv.h>
├─ lib/
│   ├─ libuv.a      # 静态库
│   └─ libuv.dll.a  # 动态库导入库（编译链接用）
└─ bin/
    └─ libuv‑1.dll  # 动态库，运行程序必须携带
```

## 动态编译命令：
```powershell
gcc hi.c -o hi.exe -L. -lmylib
```

- `-L.` 在当前目录搜索库；
- `-lmylib` 找到 `libmylib.dll.a`，完成链接；
- **编译的时候根本不碰 mylib.dll**。

> ⚠运行的时候，操作系统需要找到 `mylib.dll`。
> 
> 你现在已经把 `mylib.dll` 和 exe 在同一个目录，**运行没问题**。

或者：

```powershell
gcc main.c -I"E:\C++\install\libuv_install\include" -L"E:\C++\install\libuv_install\lib" -luv -o main.exe
```

 这条命令做了什么

1. `-I...`：去该目录找`uv.h`头文件，给编译器做语法检查。
2. `-L...`：告诉链接器去哪里找库文件。
3. `-luv`：在 lib 目录找库，**优先匹配 `libuv.dll.a`（导入库），不是 libuv.a，也不是 libuv‑1.dll**。
4. 链接器读取`libuv.dll.a`，得到 libuv 各个函数符号信息，把符号写到 main.exe 里面。
