# 创建库
## 创建头文件(mylib.h)



```h
`#ifndef MYLIB_H`
`#define MYLIB_H`

int add(int a)/*定义要引出的函数*/

`#endif`
```

## 创建实现函数文件(mylib.c)

```c
int add（Int a）{
.......
}
```


## 1.动态库


```PowerShell
gcc -shared -o mylib.dll mylib.c "-Wl,--out-implib,libmylib.dll.a"
```
- `-shared`：生成 Windows dll 动态库
- `-o mylib.dll`：输出动态库本体
- `-Wl,--out-implib,libmylib.dll.a`：传给链接器，**生成导入库**。
生成.dll文件和.dll.a文件
.dll放在exe文件同目录
.dll.a在gcc编译时导入库

> Windows 下：
> 
> - `mylib.dll`：真正存放函数机器码，**运行时需要**
> - `libmylib.dll.a`：编译链接阶段用，告诉链接 dll 里面有哪些函数；**运行不需要**

编译主程序连接库

```PowerShell
gcc hi.c -o hi.exe -L. -lmylib
```
- `-L.`：去当前目录找库文件
- `-lmylib`：找 `libmylib.dll.a`（MinGW 规则：`‑lxxx` 匹配`libxxx.dll.a` / `libxxx.a`）

启动程序
```PowerShell
.\hi.exe
```

## 2.静态库
终端
打包文件
```PowerShell
gcc -c mylib.c -o mylib.o 
```
- `-c`：只编译不链接，输出目标文件`mylib.o`，里面是 add 函数二进制机器码。
打包成静态库
```PowerShell
ar rcs libmylib.a mylib.o 
```
- `ar`：归档工具，把若干`.o`打包成`.a`静态库
- `r`替换、`c`创建、`s`生成索引
编译主程序连接库
```PowerShell
gcc hi.cpp -L. -lmylib -o hi2.exe
```
> ⚠重点坑：
> 
> 如果当前目录**同时有 libmylib.dll.a 和 libmylib.a**，`‑lmylib`优先选`libmylib.dll.a`动态导入库，不会选静态库！
> 
> 想要强制使用静态库，不能写 `-lmylib`，直接写完整文件名：

```powershell
gcc hi.c libmylib.a -o hi2.exe
```
启动程序
```PowerShell
.\hi2.exe
```
