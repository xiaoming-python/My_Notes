
> 重点：

- `&&`、`||`：**逻辑运算符，用来做条件判断（真假）**
- `&`、`|`、`^`：**按位运算符，操作二进制每一位**
- `!`：逻辑非；`~`：按位取反

表格

| 符号   | 名字   | 类型   | 作用                 |
| ---- | ---- | ---- | ------------------ |
| `&&` | 逻辑与  | 逻辑运算 | 并且，全真才真            |
| `\|` | 逻辑或  | 逻辑运算 | 或者，一个真就真           |
| `&`  | 按位与  | 位运算  | 二进制每一位做与           |
| `\|` | 按位或  | 位运算  | 二进制每一位做或           |
| `^`  | 按位异或 | 位运算  | 两位不一样则为 1          |
| `!`  | 逻辑非  | 逻辑运算 | 取真假，`!0=1`，`!非0=0` |
| `~`  | 按位取反 | 位运算  | 每一位 0 变 1，1 变 0    |## 补充：移位运算符

`<<` 左移，`>>`右移


运行

```c
1 << 2; // 0001 左移2位 →0100，等价乘以4
```
